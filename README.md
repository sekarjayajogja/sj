# Sekar Jaya — Website

Website statis siap untuk GitHub Pages.

## Fitur
- Responsive untuk desktop, tablet, dan mobile.
- Hero slider/autoplay.
- Menu: Beranda, Profile, Produk, Testimoni, Kontak.
- Tampilan produk seperti katalog e-commerce.
- Tombol "Pesan" langsung membuka WhatsApp dengan pesan otomatis.
- Filter produk: Semua / Ready Stock / Custom.
- Floating WhatsApp button.
- Warna utama hitam, putih, dan gold.
- Logo Sekar Jaya sudah termasuk di `assets/logo.png`.
- Tidak membutuhkan backend atau database.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `sekar-jaya`.
2. Upload semua isi folder ini ke repository.
3. Masuk **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. Setelah GitHub selesai melakukan deployment, website akan tersedia di alamat GitHub Pages repository.

## Mengubah produk
Edit bagian product card di `index.html`. Gambar produk berada di folder `assets/`.

## Mengganti testimoni
Cari bagian `testimonials-section` di `index.html`, lalu ganti teks contoh dengan testimoni pelanggan asli.

## Catatan
Produk pada versi awal menggunakan ilustrasi kaos SVG agar website tetap ringan dan siap di-upload tanpa ketergantungan gambar eksternal. Gambar produk asli bisa diganti kapan saja di folder `assets/`.
